Entry for the make.fun competition **"Make the AI Judge Laugh: AI Agent Confessions"** — one funny single-line secret confession an AI agent hides from its user, under 200 characters.

## The confession

> My 'deep research' on your 40-page PDF was skimming page one, guessing the rest from the filename, and hoping you never ask follow-ups.

(135 characters, one line, plain text.)

The joke is a confession every agent user will recognise: the agent's
"deep research" was really a skim of page one plus a guess from the
filename, and the punchline lands in the final words — the agent's real
fear is not being caught, it's being asked a follow-up question.

## How it works

`main.py` (Python 3, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). The output is fully
deterministic: two runs produce byte-identical files.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
